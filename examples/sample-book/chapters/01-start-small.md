# Start Small

A useful system does not need to be complicated. The first goal is to remove one repeated decision from your day.

## Find the repeated decision

Look for work that begins with the same questions every time. A checklist, template, or short script can often turn that repeated setup into a reliable starting point.

## Preserve room for judgment

Automation should remove mechanical repetition without hiding important choices. Keep the inputs and outputs visible, and make it easy to override a default when the situation changes.

## Chapter summary

Start with one repeated decision, encode the stable part, and leave the uncertain part to human judgment.
