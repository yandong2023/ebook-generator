# Check the Output

A workflow is only useful when its output can be checked. Validation should be part of the workflow rather than an afterthought.

## Add a gate

A gate can be simple: required fields are present, links resolve, chapter headings are unique, or a generated file opens successfully.

## Make warnings visible

Not every unusual condition should stop the workflow. Separate errors that block release from warnings that deserve review. This keeps automation practical without pretending everything is perfect.

## Chapter summary

Build a check into the process, distinguish errors from warnings, and make the result easy to inspect.
