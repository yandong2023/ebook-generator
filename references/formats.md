# Export Formats

## EPUB3

Use EPUB as the primary reflowable ebook format. It is appropriate for most text-heavy books and is accepted by many ebook ecosystems.

The bundled builder:

- converts Markdown to XHTML-compatible HTML;
- uses H1 chapter titles for navigation;
- embeds local images used by chapters;
- builds navigation/TOC metadata;
- adds shared CSS;
- optionally embeds a cover image.

Always validate the final EPUB. `scripts/validate_epub.py` uses official `epubcheck` when available and otherwise performs only structural sanity checks. A structural pass is not equivalent to a full EPUB specification validation.

## DOCX

DOCX is the editable handoff format. The bundled conversion preserves common headings, paragraphs, lists, blockquotes, code blocks, simple tables, links, and local images on a best-effort basis. Complex layout should be reviewed in Word/LibreOffice before delivery.

## HTML

HTML is useful as a preview and as an intermediate format for PDF generation. The builder emits one standalone file and embeds local images as data URIs when possible.

## PDF

PDF is fixed-layout. It requires the optional `weasyprint` dependency:

```bash
pip install -r requirements-pdf.txt
python scripts/build_book.py ./my-book --format pdf
```

For print-on-demand interiors, do not assume a generic PDF meets a store's current trim, bleed, margin, font-embedding, or pagination requirements. Verify the target platform's current print specifications before submission.

## MOBI / AZW3

These are not generated by the core script. If a downstream workflow truly requires them, use a current conversion tool such as Calibre after producing a clean EPUB, and validate the result in the target reader ecosystem.
