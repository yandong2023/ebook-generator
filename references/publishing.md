# Publishing Preparation

Publishing platforms change often. Treat this file as workflow guidance, not as a frozen record of current store limits or royalty rules.

## Before platform entry

Prepare a release packet containing:

- final title and subtitle
- author / contributor display names
- publisher or imprint, if any
- language and edition
- short description
- long description
- category candidates
- keyword candidates
- target audience / age range where relevant
- final EPUB and/or print interior
- final cover assets
- rights statement
- AI-content disclosure notes if the platform asks
- pricing hypothesis and rationale
- release date plan

## Metadata principles

- Do not keyword-stuff the title/subtitle.
- Do not claim credentials, awards, bestseller status, reviews, or endorsements that do not exist.
- Descriptions should sell the reader outcome while accurately representing the book.
- Keywords should describe real reader intent, not unrelated high-volume terms.
- Categories should match the actual book.

## Cover workflow

1. Write a cover brief.
2. Generate or commission art.
3. Add final typography using a deterministic design/layout tool where possible.
4. Inspect at thumbnail size.
5. Verify current platform dimensions and file requirements.
6. Check that no accidental AI-generated text remains in the art.

## KDP / Kindle and other stores

Before giving field-by-field instructions, verify the platform's current official documentation. Requirements that can change include supported files, cover dimensions, categories, keywords, pricing, royalties, DRM, AI-content disclosures, preorders, and print specifications.

For irreversible actions such as accepting terms, purchasing identifiers, setting a permanent account attribute, or pressing the final publish button, summarize what will happen and obtain explicit user authorization.

## Release QA

After upload but before final publication, use the platform's previewer and inspect:

- cover crop and thumbnail
- TOC navigation
- chapter starts
- paragraph spacing and indentation
- images and captions
- tables
- links and notes
- special characters
- page breaks / blank pages
